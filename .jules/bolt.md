## 2024-05-15 - React Array Method Optimizations\n**Learning:** When filtering large arrays in React render/useMemo functions, performing operations like `.toLowerCase()` or object allocation inside the array method loop repeatedly will significantly increase TTI (Time to Interactive) and overall render time, especially for components handling large lists (e.g., POS product grids).\n**Action:** Hoist repetitive pure transformations outside loops. E.g., pre-compute the search query using `.toLowerCase()` once before using it in a `.filter` loop, and apply early returns (skip expensive property accesses if a fast-path condition fails).
